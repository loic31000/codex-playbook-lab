# Lister les tâches créées

Implémente uniquement la Story suivante dans le repository courant.

## Story

En tant qu’utilisateur,
je veux retrouver les tâches que j’ai créées
afin de consulter ma liste de tâches.

## Critères d’acceptation

- une tâche créée reste disponible pendant l’exécution de l’application ;
- les tâches peuvent être récupérées dans leur ordre de création ;
- la fonctionnalité est couverte par des tests automatisés.

## Hors périmètre

- persistance ;
- pagination, filtrage ou tri supplémentaire ;
- interface CLI ;
- ajout de dépendances.
