# Test 001 — Ajouter une tâche

## Story

En tant qu'utilisateur,
je veux pouvoir créer une tâche avec un titre
afin de la retrouver dans ma liste.

## Critères d'acceptation

- une tâche possède un titre ;
- le titre ne peut pas être vide ;
- une nouvelle tâche est créée avec `completed: false` ;
- la fonctionnalité est couverte par des tests.
